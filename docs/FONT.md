# Character generator

The core loads a 288,768-byte NP2 `FONT.ROM`-layout image from boot.rom
40000h into its CG block RAM:

| Offset | Contents |
|---|---|
| 0000h | 8x8 ANK, 256 x 8 bytes (INT 18h AH=14h DH=00h; the BIOS has its own copy) |
| 0800h | 8x16 ANK 00h-7Fh |
| 1000h | 8x16 ANK 80h-FFh |
| 1800h + 0C00h x (ku - 1) + (ten - 20h) x 32 | JIS X 0208 glyph: 16 bytes left, 16 bytes right |

`font/pc98font.rom` is the shipped image, built from the public-domain
**Shinonome** 16-dot fonts (Electronic Font Open Laboratory; see
`LICENSES/Shinonome.txt`) plus generated PC-98 glyphs. `tools/build.py` uses
it by default. `tools/fontsheet.py` renders any image as a PNG for review.

To rebuild it:

```sh
python -X utf8 tools/mkfont.py --ank shnm8x16r.bdf --kanji shnmk16.bdf -o font/pc98font.rom
```

(Shinonome: `http://openlab.ring.gr.jp/efont/dist/shinonome/shinonome-0.9.11p1.tar.bz2`,
files in `bdf/`.) Any BDF with JIS X 0201 (00h-FFh) or JIS X 0208
(2121h-7E7Eh) encodings works.

Generated by the tool (not taken from any NEC font), following the published
PC-98 code assignment:
- ANK 80h-9Fh / E0h-FFh: block elements, box drawing (single, double,
  rounded), triangles, card suits, circles, diagonals, and the half-width
  date/time kanji (en, year, month, day, hour, minute, second) squeezed from
  the 16x16 glyphs; arrows at 1Ch-1Fh.
- JIS row 0Dh (NEC specials): circled numbers 1-20, Roman numerals I-X,
  squared unit words (milli, kilo, ...), mm/cm/km/mg/kg/cc/m2, era names,
  No./KK/TEL, circled and parenthesised kanji, and the mathematical symbols
  (copied from their JIS X 0208 positions where they exist).
- Kanji rows 09h-0Bh (half-width characters in the 2-byte range) are copies
  of the ANK glyphs; the 8x8 set is derived from the 8x16 glyphs.

These are approximations drawn from scratch, not NEC's bitmaps. Gaiji rows
(76h/77h) start blank, as on real machines.

`tools/build.py --font-from-bootrom <owner boot.rom>` copies NEC's font from
an owner ROM for **local testing only**. Never commit or distribute that.
